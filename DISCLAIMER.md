### What this mod does

It lets **every player** — not only creative / opped / cheat-mode players — use Explorer's Compass to search for a
structure and click the teleport button to travel there. It does this by injecting a Mixin into
`PlayerUtils.canTeleport` that always returns `true`; this can be turned off in the config.

### Safety notes

1. **Back up** your world and server directory before installing.
2. Teleporting bypasses Explorer's Compass's intended permission model — that is the entire point of this mod, but
   **server administrators should be aware of it**. To disable the behaviour, set `allowAllPlayersTeleport = false`
   in `config/compassunlock-common.toml`, or simply delete this mod's jar.
3. This project modifies another mod's runtime behaviour via Mixin. If Explorer's Compass changes the class or method
   name in an update, this mod stops working (the server log prints `Teleport unlock NOT active`) but it will **not**
   prevent the server from starting.
